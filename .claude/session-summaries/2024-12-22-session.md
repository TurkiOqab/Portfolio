### Theme System
- 9 themes: violet, blue, emerald, rose, cyan, orange, slate, white, light
- Light theme (`mode: 'light'`) requires special handling in previews
- Theme config in `app/lib/themes.ts`

### Font System
- 5 fonts: Outfit, Jakarta, DM Sans, Syne, Source Code
- Font config in `app/lib/fonts.ts`

### CV Import Flow
1. User uploads PDF → sent to `/api/parse-cv`
2. Claude AI extracts data → returns JSON
3. `cvImported: true` set in PortfolioData
4. BioStep shows AI indicator if `cvImported` is true
